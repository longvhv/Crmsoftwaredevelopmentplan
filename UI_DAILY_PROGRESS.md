## 🎨 DESIGN DECISIONS

### March 17 - Form Components
1. **Input Sizing:** xs/sm/md/lg/xl (5 sizes thay vì 3)
2. **Violet Focus Ring:** `ring-[var(--brand-primary)]/20` (20% opacity)
3. **Character Count:** Right-aligned, changes color when exceeding maxLength
4. **Clear Button:** Only show when has value, smooth fade-in/out
5. **Label Position:** Always above input, with required/optional indicators
6. **Helper Text:** Below input, auto-color based on state (error/success/warning)
7. **Prefix/Suffix:** Text-based, styled as `text-muted-foreground font-medium`
8. **Icons:** Left/right slots, sized according to input size

### Best Practices Established
- ✅ All form fields support `label`, `required`, `optional` props
- ✅ All form fields support `error`, `success`, `warning` states
- ✅ All form fields have `helperText` prop
- ✅ All form fields support `disabled` state với opacity 50%
- ✅ All interactive elements have hover states
- ✅ All focus states use violet ring
- ✅ All animations use 200ms duration
- ✅ All components support ARIA attributes
