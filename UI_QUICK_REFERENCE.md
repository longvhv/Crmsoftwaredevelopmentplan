## 🎓 BEST PRACTICES

### Component Design
1. **Single Responsibility** - One component, one job
2. **Composition** - Build complex from simple
3. **Consistency** - Follow design system
4. **Accessibility** - WCAG AA compliance
5. **Performance** - React.memo, virtualization
6. **Documentation** - Props, examples, guidelines

### CSS/Tailwind
1. Use design tokens (CSS variables)
2. Mobile-first responsive
3. Avoid magic numbers
4. Use utility classes
5. Extract components when repeated
6. Optimize for production

### Animations
1. Use GPU-accelerated properties (transform, opacity)
2. Keep under 300ms
3. Respect prefers-reduced-motion
4. Test on low-end devices
5. Avoid layout thrashing
